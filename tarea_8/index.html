Tipos de estilos en css

Estilos en linea

Estos estilos se van a agregar directamente en el elemento html mediante el atributo style

Este parrafo tiene estilos en linea

Estilos internos

Estos estilos se agregan en el mismo html dentro de la etiqueta <head> y para agregarlos se utiliza el elemento: <style>

Estilos internos

Estos estilos son los que se recomienda utilizar, ya que ofrece modularidad, facil mantenimiento, orden, eficiencia, entre otras ventajas, para agregar una hoja de estilos externa, dentro de la etiqueta <head> se utiliza el elemento <link> donde se especifica la ruta de nuestra hoja de estilos
